🍎 Magnet Tasks - Complete Guide

🎯 Main Features

  • Fruit-Based Task Management: Assign tasks to fruits and track their completion
  • Priority System: High, Medium, Low priorities with visual size differences
  • Admin Mode: Advanced features and extra fruits
  • Real-time Alarms: Audio notifications when tasks are due
  • Activity Tracking: Complete log of all actions and task completions

🍍 Main Screen Fruits

  • 🍍 Pineapple: High Priority (Large size)
  • 🍊 Orange: Medium Priority (Medium size)
  • 🍇 Grapes: Low Priority (Small size)
  • Click any fruit: Assign a task with due date/time
  • Priority is preset: Cannot be changed for main fruits

🔧 Admin Mode Features

  • Access: Click "Monitor" → Enter admin password
  • Extra Fruits: 🍎 Apple, 🍌 Banana, 🍓 Strawberry
  • Add to Main: Click extra fruit → Confirm → Assign task
  • Admin Fruits: Have golden border and 🔙 return icon
  • Return to Admin: Double-click admin fruit on main screen
  • Priority Setting: Admin fruits can have priority changed
  • Activity Monitor: View all tasks, completions, and statistics
  • Silence Alarms: Stop all active alarms

⚡ Task Management

  • Assign Task: Click fruit → Fill form → Save
  • Due Date/Time: Set when task should be completed
  • Alarm System: Audio alerts when tasks are due
  • Complete Task: Return fruit to basket (double-click for admin fruits)
  • Task Status: Active, Done, or Overdue
  • Search & Filter: Find tasks by priority or text

🎨 Visual Indicators

  • Fruit Size: Larger = Higher Priority
  • Golden Border: Admin fruits (can be returned)
  • 🔙 Icon: Return to admin (double-click)
  • OUT Badge: Fruit is currently on a task
  • Priority Pills: Color-coded (Red=High, Yellow=Medium, Green=Low)

🔊 Alarm System

  • Audio Alerts: Plays when tasks become due
  • Auto-Stop: Alarms stop when tasks are completed
  • Admin Control: Silence all alarms from admin panel
  • Return Control: Returning fruits stops their alarms

📊 Activity & Statistics

  • Activity Log: Complete history of all actions
  • Statistics: Task counts, completion rates
  • Real-time Updates: Live updates across browser tabs

⌨️ Keyboard Shortcuts

  • Ctrl+Shift+A: Open Admin Mode
  • Ctrl+Shift+M: Open Monitor Mode
